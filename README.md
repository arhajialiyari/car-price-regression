# Car Price Regression

A machine learning project focused on used car price regression using the CarDekho dataset.

## Dataset

The dataset contains 301 records and 9 columns.

Source: [Vehicle Dataset from CarDekho - Kaggle](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho)

The dataset is not included in this repository.

## Notebook

The original Jupyter Notebook is available in the `notebooks` directory.

## Environment

- Python 3.11.7
- Conda
- Visual Studio Code
